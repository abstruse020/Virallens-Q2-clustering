# Q2: Custom Domain Embedder vs Baseline

Fine-tune a small sentence-embedding model on a set of domain PDFs, then compare it against the off-the-shelf model using clustering metrics.

- **Baseline:** pretrained `all-MiniLM-L6-v2`, reduced to 64 dims with PCA (no training).
- **Custom:** the same encoder plus a 64-dim projection head, fine-tuned with a contrastive loss on chunks from the training documents. The projection starts from the same PCA, so the two models are identical before training.
- **Comparison:** both are clustered with the same algorithm (KMeans), the same k, and the same seed, then scored with the same metrics.

## 2. Setup

Python 3.10+ is recommended.

```bash
pip install pypdf pymupdf sentence-transformers torch scikit-learn matplotlib numpy tqdm
```

- `pypdf` is the default PDF extractor. `pymupdf` is an alternative (better on multi-column layouts). Switch with `EXTRACTOR = "pypdf" | "pymupdf"` at the top of `preprocess.py`. You only need the one you use.
- First run downloads `all-MiniLM-L6-v2` from Hugging Face (internet needed once).
- **GPU:** 6 GB of VRAM is enough (batch 64, sequence length 128, fp16). If you hit out-of-memory, run with `--batch-size 32`. It also runs on CPU, more slowly.
- Scanned (image-only) PDFs are skipped and listed under `skipped` in `data/processed/stats.json`. They would need OCR.

## 3. How to run

### Full pipeline (one command)

```bash
python main.py
```

This runs, in order:
1. **preprocess** (skipped if `data/processed/chunks_all.jsonl` exists)
2. **baseline** (skipped if `outputs/baseline/metrics.json` exists)
3. **custom** (skipped if that variant's `comparison.json` exists)
4. **report**: prints a baseline-vs-custom table and saves `outputs/comparison.md`

### Running experiment variants

Each variant trains its own model and saves to its own folder, so nothing is overwritten.

```bash
python main.py --tag top2       --top-layers 2            # fine-tune only the top 2 transformer layers
# Other variants I was trying (but not in summary)
python main.py --tag pfar0      --p-far 0                 # nearby-chunk positives only
python main.py --tag top2_pfar0 --top-layers 2 --p-far 0  # both
python main.py --tag pfar0_nomask --p-far 0 --no-mask-same-doc
```

| Option | Meaning |
|---|---|
| `--tag NAME` | Variant name; results go to `outputs/custom_NAME/`. Without it, the default variant goes to `outputs/custom/`. |
| `--top-layers N` | Fine-tune only the top N of the 6 transformer layers (plus the projection). `0` = projection head only. Omit = whole encoder. |
| `--p-far X` | Probability that a positive is *any* chunk of the same document instead of a nearby one. `0` = nearby only. Default `0.25`. |
| `--window W` | "Nearby" means within ±W chunk positions. Default `3`. |
| `--pairs-per-chunk N` | Positives sampled per anchor chunk. Default `2`. |
| `--no-mask-same-doc` | Do not exclude same-document chunks from the negatives. |
| `--epochs`, `--lr-encoder`, `--lr-proj`, `--batch-size`, `--dim`, `--seed` | Standard training settings. |

`run_custom.py` accepts the same options directly: `python run_custom.py --tag top2 --top-layers 2`.

### Forcing re-runs

| Flag | Effect |
|---|---|
| `--force-preprocess` | Re-parse PDFs and re-chunk. **Also re-runs the baseline and custom stages** (chunks and split change). |
| `--force-baseline` | Recompute baseline embeddings and clustering. |
| `--force-custom` | Re-train the selected variant even if its results exist. |

### Only viewing results

```bash
python main.py --stages                      # print the table for all variants, run nothing
python main.py --stages --compare custom top2 pfar0   # only these variants
```

`--stages preprocess baseline` (or any subset) runs only those stages.

## 4. Viewing the results

**Console:** at the end of a run you get an aligned table with baseline and every variant as columns. `*` marks the best value in each row, followed by "rows won" and each variant's settings.

**Files**

| Path | What it is |
|---|---|
| `outputs/comparison.md` | Markdown version of the table, ready to paste into a report. |
| `outputs/baseline/metrics.json` | Baseline: k sweep, chosen k, metrics, top terms per cluster, document composition of each cluster. |
| `outputs/baseline/k_sweep.png` | Silhouette and Davies-Bouldin vs k. |
| `outputs/baseline/cluster_map.png` | 2D t-SNE: left colored by cluster, right by source document. |
| `outputs/baseline/clusters.csv` | `chunk_id, doc_id, split, cluster` for each chunk. |
| `outputs/baseline/embeddings_full.npy`, `embeddings_reduced.npy` | 384-dim and 64-dim baseline embeddings. |
| `outputs/custom*/comparison.json` | Baseline and custom metrics plus the variant's config. This is what the table reads. |
| `outputs/custom*/metrics.json` | Loss history, k sweep, top terms, document composition, config. |
| `outputs/custom*/loss_curve.png` | Train and validation InfoNCE loss per epoch (epoch 0 = before training). |
| `outputs/custom*/k_sweep.png`, `cluster_map.png`, `clusters.csv`, `embeddings.npy` | Same as the baseline versions. |
| `outputs/custom*/model/` | Saved encoder (`st/`), projection (`proj.pt`), `config.json`. |

### Reading the metrics

| Metric | Direction | Notes |
|---|---|---|
| Silhouette (cosine) | higher | Cohesion vs separation of clusters. |
| Davies-Bouldin | **lower** | Average similarity between each cluster and its closest neighbor. |
| Calinski-Harabasz | higher | Between-cluster vs within-cluster dispersion. |
| ARI / NMI vs `doc_id` | higher | Agreement between clusters and source documents. Only meaningful if documents are topically distinct. |
| `*_test_docs_only`, `*_test_subset` | higher | Scored only on held-out (test) documents, using the global clusters. |
| `*_test_recluster` | higher | Test chunks are re-clustered on their own (k = number of test documents). The cleanest held-out check. |

Rows labelled "all" include documents the custom model trained on, so they favor the custom model. Put more weight on the test-document rows.

A test-document ARI/NMI needs at least 2 held-out documents. With fewer, they show `n/a`.

## 5. What each file does

### `main.py`
Entry point. Runs preprocess, baseline and custom stages (skipping any whose outputs exist), forwards variant options to `run_custom`, and builds the comparison table across all `outputs/custom*` folders. Works from `src/` or one level above it.

### `preprocess.py`
PDF to chunks.
- Extracts text per page (`pypdf` or `pymupdf`), flags scanned files.
- Removes repeated headers/footers (lines repeated across at least 40% of pages, with digits normalized) and page numbers.
- Cleans: Unicode normalization, de-hyphenation, joins hard-wrapped lines, drops stray fragments, cuts a trailing References section. URLs and emails are kept.
- Chunks by sentences to about 100 words with 1 sentence of overlap; drops chunks under 20 words.
- Splits **by document** (default 20% of documents held out, seed 42) to avoid leakage.
- Saves JSONL files and `stats.json`. `load_chunks("all" | "train" | "test")` loads them for later stages.

### `embed.py`
Embedding helpers: load a SentenceTransformer, `embed_texts` (normalized, batched), PCA fit/apply for dimension reduction (fitted on train chunks only), and save/load of `.npy` arrays.

### `cluster.py`
Clustering and separation metrics: KMeans and Agglomerative, k sweep and selection by silhouette, `cluster_metrics` (silhouette, Davies-Bouldin, Calinski-Harabasz, ARI, NMI), TF-IDF top terms per cluster, and each cluster's composition by document.

### `evaluate.py`
Plot helpers: k-sweep plot, t-SNE cluster map (by cluster and by document), and the training loss curve.

### `train.py`
The custom model.
- `build_pairs`: self-supervised positives from the same document (nearby chunks, plus document-wide chunks with probability `p_far`).
- `ProjectedEncoder`: MiniLM encoder plus a linear projection to `dim`, L2-normalized, with a SentenceTransformer-style `.encode()`.
- Projection initialised from PCA, so training starts from the reduced baseline.
- `info_nce`: symmetric contrastive loss; same-document chunks are masked out of the negatives (optional).
- `train_embedder`: AdamW with separate learning rates for encoder and projection, warmup and linear decay, fp16 on GPU, optional freezing of all but the top N layers, per-epoch train and validation loss.
- `save_custom` / `load_custom`.

### `run_baseline.py`
No-training baseline: embeds all chunks with the pretrained model, reduces with PCA, sweeps k, clusters, computes metrics, and saves results and plots to `outputs/baseline/`.

### `run_custom.py`
Trains one custom variant, embeds all chunks, clusters with the baseline's k and seed, computes all metrics (including held-out-only ones) for both models, and saves everything to `outputs/custom/` or `outputs/custom_<tag>/`. Holds the default settings (`DEFAULTS`) and the command-line options.

## 6. Troubleshooting

| Problem | Fix |
|---|---|
| Changed cleaning or chunking settings | Delete `data/processed/extracted/` (or use `--force-preprocess`) so cached text is rebuilt. |
| `No PDFs found in ../data` | Put PDFs in `data/` next to `src/`. |
| PDF listed under `skipped` (scanned/empty) | It has no text layer; OCR it first. |
| CUDA out of memory | `--batch-size 32` (or 16). |
| `baseline dim X != dim Y` | The custom `--dim` must equal the baseline's reduced dimension (64 by default; change `REDUCED_DIM` in `run_baseline.py` and re-run with `--force-baseline`). |
| Validation loss disabled warning | Fewer than 2 test documents. Raise `TEST_FRACTION` in `preprocess.py`, then `--force-preprocess`. |
